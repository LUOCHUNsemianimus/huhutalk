## 一、改动原则

1. **降调**：把「死亡叙事」降级成「游戏里的日常磕碰」，去掉 `倒下 / 眼前 / 鬼门关 / 拿命折腾` 这类重词。
2. **去「事故报告」感**：现在是「死因 / 位置 / 操作 / 结果」四段 bullet，建议压成一句事实。
3. **短**：每条注入都加一句长度约束（「一两句就够」、「主人多半正忙着打架」）。
4. **保留人设自由**：仍然只给「按你自己的性子来」，不写「要坦率」之类（会盖掉傲娇人设）。
5. **事实仍然准确**：死因用服务器原始提示、剩余瓶数用实测值，不写死。
6. **不改逻辑**：只换字面量；距离分档、双女仆分工、第 N 次吐槽这些结构全部保留。

### A. 第 1 / 2 / 3 次救援 · 即时叙事

#### A1 事实与动作（单女仆）

**现状**（四段 bullet）：
```
【刚刚发生的事】主人刚刚死了一次，是你把他救回来的。
· 死因（服务器原始死亡提示）：{原版提示}
· 位置：{主人倒下时你就在他眼前 / 远远地看到了他出事 / 是隔着手机才发现主人出事的}
· 你的操作：你取出一瓶「{药}」，当场喂给他喝下 / 就近送过去喂给他喝下 / 隔着手机把「{药}」送过去，喂给他喝下
· 结果：他回了约 {N} 点血，又站了起来。
```

**建议**（压成一句，距离并进动作里）：
```
距离远（跨维度）：
【刚刚的事】{原版死亡提示}。你隔着手机递了一瓶「{药}」过去，人已经没事了。

距离近（≤ 50 格）：
【刚刚的事】{原版死亡提示}。你就在附近，赶过去喂了他一瓶「{药}」，人已经没事了。

就在身边（≤ 10 格）：
【刚刚的事】{原版死亡提示}。你就在旁边，顺手喂了他一瓶「{药}」，人已经没事了。

（喷溅 / 滞留型：把"喂了他一瓶「{药}」"换成"把一瓶「{药}」砸在他身上"）
（有抗火：追加一句"顺带还补了一瓶「{抗火}」，免得他接着烧。"）
```

## 五、❓ 需要你拍板

1. **「死」字口径**：我这版是「提示词里完全不出现死字」，只用原版死亡提示 + 「捞了回来 / 人没事了」；但你举的例子里保留了「主人 xxx 死了」。两者语气差别不小，要不要保留一处？放哪里？
2. **回血点数**（「他回了约 N 点血」）：我建议只留在聊天页气泡里，提示词里删掉。要保留吗？
3. **长度**：写「一两句就够」还是给硬字数（如「不超过 30 字」）？实测上具体字数更管用，但可能把她的风格压平。
4. **抗火那句**要不要也进记忆文案（A7）？目前只在 A1 里出现。
5. **「人已经没事了」**这个措辞：比「你把他救回来了」更轻，但也更模糊（没明说是你救的）。要哪种？
