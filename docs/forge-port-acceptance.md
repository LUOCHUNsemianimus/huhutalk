# HuhuTalk Forge 1.20.1 候选版人工验收清单

本清单供用户在独立 1.20.1 实例中按正常使用顺序逐项勾选。**未实际勾选的项目不得视为已通过。**
开发侧已执行的构建、GameTest 和客户端 smoke 只覆盖下文“已由开发侧验证”的范围，不等同于本清单完成。

## 已由开发侧验证（无需重复勾选）

- 固定 JDK 17 build（含主源码、测试源、gametest 源、reobf）通过。
- 3 个原生 GameTest 通过：真实 37 物品与预览/NBT、药水、RecipeManager 加载 3 个祭坛配方。
- 客户端 smoke 8 项检查通过：模型屏、设置页、浮窗、后摄、自拍与 2 张本地照片保存；未发 LLM 请求。
- 19 个 JSON、450 个中英双语 key 与 printf 参数、3 个祭坛配方、loot、tag 审计通过。

## 前置准备

在独立实例中安装 Minecraft 1.20.1、Forge 47.4.16、Java 17、车万女仆 1.5.3 Forge（最低 1.5.3），
可选安装 JourneyMap；将 `build/libs/huhutalk-1.1.0-forge1.20.1-dev.jar` 放入 `mods`。不要在本项中
改动原 pianchang 实例。进入世界前建议备份存档与配置。

## 用户勾选清单

- [ ] **1. 启动与前置**：独立实例能启动，模组列表显示 HuhuTalk，无缺失前置或版本拒绝；服务端与
  客户端模组版本一致。
- [ ] **2. 进世界礼包**：首次进入世界收到开局礼包，含 Pro 版手机、电话手表与 Wi-Fi 方块。
- [ ] **3. 手持 Pro 与桌面**：手持 Pro 手机打开桌面；各 App 图标可打开，设置 App 图标可移动、
  不可删除。
- [ ] **4. O 浮窗、侧键与输入**：按 O 唤出/收起独立悬浮屏，无需手持手机；侧键可用；能正常输入，
  并在 Minecraft 控制设置中修改绑定后仍有效。
- [ ] **5. 女仆配饰与手表 Wi-Fi**：给女仆装备配饰/手表后连接 Wi-Fi，手机能识别对应女仆并显示状态。
- [ ] **6. 真实聊天与移动工具**：配置车万女仆聊天模型后发送真实消息并收到回复；自然语言移动指令
  （前往坐标、驻留、回到身边）按预期执行。
- [ ] **7. 录音与语音输入**：麦克风可用时录音/语音输入能采集并用于消息；无麦克风或无权限时有可理解
  的提示，不崩溃。
- [ ] **8. 后摄、自拍、图库与发送**：后摄拍照成功保存；自拍预览左右镜像、保存方向正常；图库能看到
  照片；聊天内相机可确认、发送、重拍。
- [ ] **9. 传文件（玩家与女仆）**：本模组只支持玩家→女仆、女仆→玩家两个方向，不支持玩家↔玩家
  传输。分别验证两个方向：发送方与接收方都能看到传输状态；接收方可领取或丢弃；物品数量正确、
  不丢失、不复制；接收方背包已满时不能领取，物品仍保留在传输中可另行处理。
- [ ] **10. 服务端档案与换档**：服务端档案页能看图文记录；传输状态正确；退出重进后记录保留；切换
  存档后不串档。
- [ ] **11. 祭坛 3 配方与 WiFi 掉落**：祭坛能按配方合成电话手表、智能手机、Wi-Fi 方块；Wi-Fi 方块
  被镐挖掘时正常掉落。
- [ ] **12. 救援真死**：女仆救援触发真死流程后，约 100 tick（5 秒）进行对账；符合救援条件时在
  死亡维度、死亡坐标按死亡视角复活，同时保留原床位登记（原床位不是本模组药水救援的复活点）。
  无救援标记的普通手动重生仍按原版床位/出生点处理，不被救援逻辑干扰。两类复活分别确认。
- [ ] **13. 补给与救援物品**：活人远程补给（药水/食物）与死亡救援补给（治疗药水及必要抗火药水）
  分别验证；物品与叙事文本按预期出现，药水类型/效果正确。食物只用于活人远程补给，不用于死亡玩家的救援。
- [ ] **14. JourneyMap 可选与跨维度**：未装 JourneyMap 时其余功能正常；安装后路径点在主世界、
  跨维度及负坐标下指向正确。
- [ ] **15. 退出重进与失焦观察**：退出重进后手机、档案与设置状态合理；游戏失焦再聚焦时未出现旧卡顿
  现象（若出现，按 `docs/worklogs/2026-10-26-focus-stall.md` 保存现场）。
- [ ] **16. FOV/GUI 缩放下的屏幕与相机**：在常用 FOV 与 GUI 缩放下检查模型屏、设置页、浮窗和前后摄
  取景；确认边缘裁切可接受，必要时记录具体 FOV/缩放值。
