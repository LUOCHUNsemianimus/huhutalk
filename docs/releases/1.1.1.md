# HuhuTalk 1.1.1

Minecraft **1.21.1** · **NeoForge** · Java **21** · 需要 / Requires **Touhou Little Maid**

## 中文

本次更新加入服务端手机归档、只读存储页，以及手机历史检索与引用；同时修复救援叙述开关，并更新识图平台预设。归档范围是当前主人与当前女仆的手机历史，旧消息离开 TLM 当前对话上下文后仍可回看。

### 新增与改进

- **服务端手机归档**：长期保存当前主人与当前女仆的手机文字、图片及双向物品传输事件。图片按内容哈希存入世界目录；传输事件记录发送、领取与丢地结果，是只读审计，不会重发物品。
- **手机存储页**：从女仆资料页进入只读聊天档案，分页浏览文字、图片和结构化传输事件，点击后按需查看归档图片。本页不合并本机聊天记录，不提供删除归档或领取物品的按钮。
- **历史检索与引用**：在手机聊天中可让女仆检索当前主人与当前女仆的归档历史，并把找到的原话、图片或真实物品事件引用到回复。引用只挂在本次回复断句后的第一条气泡上，显示原作者、原消息预览与原发送时间；旧档时间未知时显示未知，不用当前时间补造。检索是原话/物品名/媒体标签的字面匹配，不是向量语义搜索；依赖模型支持工具调用，并非每次对话都会自动使用，已找到也不等于必须引用。
- **物品同发上下文绑定**：玩家把物品与文字放在同一条手机消息中发送时，物品事件绑定到同一轮对话上下文，归档不再把事件与对应消息拆散；女仆发件的待领取事件也随当前回合归档。
- **识图平台与预设**：豆包预设更新为 Seed 2.1 Pro / Lite / Turbo 与 Seed 2.0 Mini，并更新平台图标与名称显示；自定义模型仍走原输入通路。不同型号不统一称作 2.1。

### 修复与调整

- 修复**救援叙述开关**：开关状态会同步到服务端，关闭后只停止 AI 救援叙述，药水救援本身仍照常执行。
- 提供**归档导出/导入基础**，兼容读取旧 schema1 记录和缺少引用字段的 schema2 记录；导入按 ID 幂等并保留冲突处理。

### 升级与兼容

- 本发布包仅适用于 **Minecraft 1.21.1 / NeoForge**；**Forge 1.20.1 分支暂未同步本轮功能**。需要 Java 21、NeoForge 21.1.243 或更高的 1.21.1 对应版本，以及车万女仆（元数据最低 1.5.0；开发验收使用 1.5.3）。
- **网络协议已变化**（`huhutalk-phone-quote-v1`）：**多人服的客户端与服务端都必须升级到 1.1.1**，不能与旧版本混用。
- 服务端归档**不等于车万女仆完整的 AI 工作上下文**，本轮未实现完整 provider；不承诺重建旧版本从未归档的数据，旧客户端历史和未接通入口也不会自动补档。归档覆盖为 `partial`，未匹配只表示当前归档里没有找到。
- 本机聊天显示清理不等于删除服务端长期归档；本版本没有新增“忘记/删除归档”UI。
- 归档导出/导入只是基础能力，**未集成 Maid File Manager（MFM）的 `.maid` provider**；引用图片或物品事件只显示摘要，不重放物品，也不对旧图片重新识图。女仆发图的引用结构已预留，但这不是“女仆现在会发图”的新功能。
- 升级前请备份存档与配置。普通 TLM 面对面回调没有可验证 sender 时不开放归档访问。

### 验证边界

本轮交付以 49 项 JUnit（构建不跳过）、94 项原生链路检查、456 个自有双语键和六张上游检查截图为依据，对应本次功能的源码状态。原生检查不发起真实付费 LLM/TTS 请求，也未进行 Forge 运行实测；发布版本重新构建与资源审计由上游核对。

## English

This update adds a server-side phone archive, a read-only storage page, and phone history search with quoting, along with a rescue narrative toggle fix and updated vision-provider presets. The archive covers the current owner and maid; messages remain readable after leaving TLM's current conversation context.

### Added and improved

- **Server-side phone archive**: retains phone text, images and two-way item-transfer events for the current owner and maid. Images are content-addressed in the world folder; transfer events record sent, claimed and dropped outcomes as a read-only audit and never re-send items.
- **Phone storage page**: a read-only chat archive opened from the maid profile, paging through text, images and structured transfer events and loading archived images on demand. It does not merge local chat history or offer archive deletion or item claiming.
- **History search and quotes**: in phone chat, ask the maid to search archived history for the current owner and maid and quote a found message, image or real item event. A quote appears only on the first bubble of the segmented reply and shows the original author, preview and send time; unknown legacy times are shown as unknown rather than filled with the current time. Search is literal matching of wording, item names and media tags, not vector semantic search. It depends on model tool-calling support, is not used automatically in every conversation, and a successful search does not require a quote.
- **Item co-send context binding**: when a player sends an item together with text in one phone message, the item event is bound to the same conversation turn, so the archive no longer separates them. Queued maid-to-player transfers are archived in the current turn as well.
- **Vision providers and presets**: the Doubao presets now list Seed 2.1 Pro / Lite / Turbo and Seed 2.0 Mini, with refreshed platform icons and names; custom models keep the existing input path. Not every model variant is called 2.1.

### Fixed and adjusted

- Fixed the **rescue narrative toggle**: its state now syncs to the server, and disabling it stops only AI rescue narration while potion rescue still runs normally.
- Added **archive export/import groundwork**, with compatible reading of legacy schema1 records and schema2 records missing quote fields; imports are idempotent by ID and retain conflict handling.

### Upgrade and compatibility

- This package targets **Minecraft 1.21.1 / NeoForge only**; the **Forge 1.20.1 branch has not received these features yet**. It requires Java 21, NeoForge 21.1.243 or newer for 1.21.1, and Touhou Little Maid (metadata minimum 1.5.0; development verification uses 1.5.3).
- **The network protocol changed** (`huhutalk-phone-quote-v1`): **both client and server on a multiplayer server must upgrade to 1.1.1** and cannot be mixed with older versions.
- The server archive is **not Touhou Little Maid's complete AI working context**, and this round does not implement a full provider. Data never archived by older versions cannot be reconstructed, and old client history or disconnected entry points are not backfilled automatically. Archive coverage is `partial`; a miss means only that the current archive had no match.
- Clearing local chat display does not delete the server-side archive; this version adds no "forget/delete archive" UI.
- Archive export/import is groundwork only, and the **Maid File Manager (MFM) `.maid` provider is not integrated**. Quoted images or item events show summaries only, do not replay items, and do not re-run vision on old images. The maid-image quote structure is reserved; it is not a new "maid can send images" feature.
- Back up worlds and configuration before upgrading. Archive access is not opened for ordinary face-to-face TLM callbacks without a verifiable sender.

### Verification scope

This delivery is supported by 49 JUnit tests (not skipped in the build), 94 native-chain checks, 456 bilingual keys and six upstream-reviewed screenshots, corresponding to the feature source state. The native checks do not make paid LLM/TTS requests and no Forge runtime test was performed; the release build and resource audit are rechecked upstream.
