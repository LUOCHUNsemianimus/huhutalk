# HuhuTalk 1.1.0 — Forge 1.20.1

Minecraft **1.20.1** · Forge **47.4.16** · Java **17** · Touhou Little Maid **1.5.3+（Forge）**

## 中文

HuhuTalk 的 Forge 1.20.1 移植版本，已通过用户正常使用场景的功能逻辑验收。

- 支持手机聊天、图片识别与发送、后摄及自拍、物品传输和移动等工具。
- 保留服务端图文与传输档案、远程补给及死亡后的药水救援。
- 适配 Forge 网络分片、Java 17、1.20.1 物品 NBT、渲染与配方资源。
- JourneyMap 为可选依赖；未安装时路径点相关功能不可用。

**补给与救援前提**：女仆必须在配饰栏佩戴 HuhuTalk 手机（建议 Pro），并保持加载、持有可用药水或食物。活人补给在生命值低于最大值 50% 或饱食度低于 6 时触发。死亡救援登记要求玩家携带 Pro 手机；死亡掉落手机不会取消已经登记的救援。符合条件时约 5 秒后在死亡点复活，随后才触发 LLM 叙事。

本版本不包含 Maid File Manager 的迁移接口接入，也尚未实现女仆搜索聊天档案的工具。光影与第三方组合兼容性以实际测试为准。

## English

Forge 1.20.1 port of HuhuTalk, accepted by the author after normal gameplay verification. Includes phone chat and photography, image recognition, item transfer, movement tools, server-side archives, remote supplies and potion rescue.

Requires Java 17, Forge 47.4.16 and Touhou Little Maid 1.5.3+ for Forge. JourneyMap is optional. Equip the maid with a HuhuTalk phone in her bauble slot and keep her loaded with usable supplies. Death rescue requires a Pro phone on the player when the death is registered; dropping it on death does not cancel a scheduled rescue. Rescue occurs about five seconds later, before the LLM narration.

Maid File Manager migration integration and the chat-archive search tool are not included. Shader and third-party combinations have limited verification coverage.

## 验证 / Validation

Java 17 build and reobfuscation; 8 independent behavior checks; resource audit; 3 native Forge GameTests; camera/UI client smoke; supply/rescue tests with a maid phone, death drops, and a no-phone negative control; user gameplay acceptance.
