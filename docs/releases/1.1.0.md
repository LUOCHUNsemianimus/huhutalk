# HuhuTalk 1.1.0

Minecraft **1.21.1** · **NeoForge** · Java **21** · 需要 / Requires **Touhou Little Maid**

## 中文

本次更新带来实体手持手机与全新物品模型、自拍前摄、扩展的女仆识图配置，以及中英文界面和手册。

- 自拍实时预览左右镜像，保存照片恢复正常方向；桌面相机直接保存，聊天相机保留确认与重拍。
- 可选择识图平台与模型，并填写玩家、女仆的外貌描述以提供识别上下文。
- 更新桌面图标和布局管理；设置图标可移动，不可删除。
- 设置 App 新增「显示与渲染」，集中管理比例、大小、字体倍率和亮度；图标风格仍在 HuhuTalk 内部设置。
- 「墨水屏」默认关闭：屏幕在光影处理后绘制。开启后参与光影效果，只改变渲染顺序，独立悬浮屏不受影响。
- 优化 Iris 下的自拍开销和兼容性，改善 BSL 下默认屏幕绘制的重影/泛光。
- O 键无需持有手机即可开启独立悬浮屏，以手机光标和确认键拖动状态栏；改善手持屏幕的生存 HUD 遮挡。
- 更新新手礼包，修复手册物品配图并改善手册分段。

升级前请备份存档和配置。需要 NeoForge 21.1.243 或更高的 1.21.1 对应版本，以及车万女仆（元数据最低 1.5.0；开发验收使用 1.5.3）。Iris 与光影包为可选项，不随模组分发；并非所有光影组合都已验证。模型服务可能收费，识图会把图片和相关提示交给所选服务。

## English

This update brings a handheld phone experience and refreshed item models, selfie photography, expanded maid vision configuration, and a Chinese/English interface and manual.

- Mirrored live selfie preview with normally oriented saved photos; immediate desktop camera saving and the existing chat confirmation/retake flow.
- Select vision providers/models and describe player/maid appearances to provide identity context.
- Refreshed desktop icons and layout management; the Settings icon can move but cannot be deleted.
- New Display & Rendering page in the Settings app for aspect ratio, size, font scale and brightness. Icon style remains in HuhuTalk's internal settings.
- E-ink Screen is off by default, drawing the screen after shader processing. Enable it to participate in shader effects. It changes render order only and does not affect the standalone floating screen.
- Reduced Iris selfie overhead and improved compatibility; improved the default phone-screen path for BSL ghosting/bloom.
- Open the standalone screen with O without holding a phone, then drag its status bar using the phone cursor and confirm key. Improved survival HUD clearance for the held screen.
- Updated starter kit, corrected item illustrations and improved manual paragraph spacing.

Back up worlds and configuration before upgrading. Requires NeoForge 21.1.243 or a newer build for 1.21.1 and Touhou Little Maid (metadata minimum 1.5.0; development verification uses 1.5.3). Iris and shader packs are optional and distributed separately; not every shader combination has been tested. Model services may charge fees; image recognition sends images and related prompts to the selected service.
