# 2026-10-29：手机历史检索 / 引用验收工作日志

项目：HuhuTalk（NeoForge 1.21.1 主线）。本日志记录手机归档检索与引用功能的最终实现、验收证据和使用边界，供后续回归与交付审查参考。

## 目的与变更范围

让玩家能在 HuhuTalk 手机聊天中查询当前主人与当前女仆已归档的手机历史，并把指定原话、图片或真实物品事件作为只读引用挂到女仆回复上。工作范围集中在归档工具、引用协议/气泡和原生验收驱动；没有复制检索存储，也没有把历史文本当作新指令或重放物品事件。

## 实现与复用

- 复用既有 `ArchiveStore` 的原话、图片、观察和双向物品事件记录，不新增索引或第二套存储。
- 检索/读取使用真实 TLM `ITool` 注册、`codec()` 与 `onCall()`；工具为 `huhutalk_search_chat_history` 与 `huhutalk_get_chat_message`。
- 权限由服务端从回调推导 owner/stableId，普通 TLM 面对面回调没有可验证 sender 时不开放归档。
- 引用由 `PhoneMessageQuote` 统一派生；只在上层回复元数据记录 `quotedMessageId`，不覆盖 `turnId` / `relatedMessageId`。气泡仅在本回复断句第一条携带引用，header 为作者+单行预览、右上原发送时间，正文在下方正常显示。
- schema2 新增可选 `quotedMessageId`；旧 schema1 和缺少该字段的 schema2 记录兼容读取，导出导入与 ID 幂等/冲突测试通过。

## 验收策略与边界

- 原生 fixture 不发起真实 LLM HTTP 付费请求，而是直接走已注册工具、真实归档、权限和 S2C/cache/引用路径。它证明这些链路，不证明付费模型会自主选择并调用工具；后者仍需真实用户场景验收。
- 普通关键词匹配不是向量语义搜索；未匹配不代表事情没发生，归档覆盖为 `partial`。普通 TLM 面对面回调无可验证 sender 时不开放归档。
- 图片引用和双向物品事件基于真实归档类型；`MAID` 图片引用结构已预留，但不是女仆发图功能，也不是旧图重新识图。
- 手机本地聊天显示清理不等于服务端归档删除；本版未新增遗忘 UI。
- 联机 client/server 必须同新构建，网络版本为 `huhutalk-phone-quote-v1`；未声称兼容旧 wire，也未同步 Forge 分支或实现 MFM 适配 SPI。
- 本日志不记录不准确的提交 SHA；最终 jar 资源、driver 隔离、双语键和原基线非授权文件由上游在收尾审查中再次核对。
